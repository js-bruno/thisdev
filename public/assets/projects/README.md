# previews dos projetos

Os cards da página `/projects/` procuram estes arquivos:

- `home-sever.gif`
- `cold-breeze.gif`
- `spotify-in-github.gif`

Até os GIFs chegarem, os cards mostram os posters `.webp` que estão nesta pasta.
Quando os GIFs forem adicionados, eles tocam no hover do card.

Tamanho recomendado: até ~560px de largura, 10–15 fps e menos de 2 MB.
Se quiser, dá para trocar por WebP animado ou `<video>` depois.
